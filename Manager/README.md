# 星河插件管理器

## 先打开工具

解压便携包，双击 **XHPluginManager.exe**。安装插件、更新词典和备份都不需要额外安装 Python。

1. 选择你的工程 `.uproject` 文件。
2. 选择你实际使用的虚幻引擎目录（选安装目录或它里面的 `Engine` 均可）。
3. 点击 **检查更新**，找到匹配包后点击 **安装 / 更新插件**。
4. 安装前先保存工作。如果 UE 正在运行，工具会询问是否正常关闭；同意后在 UE 中处理保存提示，退出后继续安装。
5. 安装完成后打开工程，在顶部找 **节点汉化** 菜单。

默认更新仓库为 <https://github.com/Yck0701/XHNodeChinese-new>。安装包与共享词典在此公开发布，更新器不需要访问私有源码仓库。

**没有网络或还没发布？**点击 **使用随包离线版本**，同样可以检查和安装。也可以通过“本地清单”选择别处的 `manifest.json`。请保留 `release` 文件夹中的全部 ZIP 文件。

## 启动检查与工具更新

默认每次启动在后台检查更新；取消“启动时检查更新，发现新版后询问下载”可关闭。顶部三个卡片分别显示工具、插件、共享词库状态。不联网成功时会明确显示“离线缓存，尚未确认最新版本”。

发现管理器、当前工程插件或共享词库有更新时，会弹窗列出版本并询问 **是否下载**。选择“否”即可继续使用。下载只保存更新包，不会关闭 UE 或修改工程；断网使用缓存清单时不会弹出新版本提醒。

管理器下载完成后会询问是否打开新版；插件和词库下载后，分别点击“安装 / 更新插件”和“更新共享词库”应用。原来的“下载并打开新版工具”按钮也可使用，设置继续沿用，旧目录保留。

安装、更新词库、替换或恢复前，如果发现 UE 正在运行，会列出进程并询问 **是否关闭**。只有同意后才请求正常退出；未保存内容由 UE 自己提示保存，不会强制结束进程。拒绝、在 UE 中取消退出或超过 90 秒未退出时，更新暂停，下载包保留。没有窗口的命令行进程需要手动退出。单独下载或备份无需关闭 UE。

## 初始共享词库

新版插件安装即带有通用词条和长说明。点击“更新共享词库”可更新基础译文，个人 CSV 保持不变；同名个人译文优先。请先关闭 UE，更新前自动备份共享词库。

基础文件位于插件 Dictionaries/Shared.csv 和 SharedLongText.csv。备份中的 shared- 开头 ZIP 可通过“恢复备份”恢复。

## 更新共享词典

进入 **词库与备份**：

- **备份当前文件**：同时备份个人词典和长文本，原文件不变。
- **从更新源替换**：选择替换两份文件、仅词典或仅长文本，然后应用最新共享版本。
- **离线包替换**：手动选择 `XHShared-日期.zip`。
- **恢复备份**：选择 `dictionary-` 或 `shared-` 开头的备份文件，还原当时的两份文件。恢复前也会自动备份当前内容。

**替换是覆盖，不是合并。**自己的译文会先保存在备份中，需要时可恢复。为了避免 UE 的自动采集或保存与文件替换冲突，请在替换、恢复前关闭 UE；单独备份无需关闭。

文件位置（相对于工程）：

| 内容 | 路径 |
| --- | --- |
| 个人词典 | `Plugins/XHNodeChinese/Dictionaries/User.csv` |
| 长文本翻译 | `Saved/XHNodeChinese/LongText.csv` |
| 备份 | `Saved/XHNodeChinese/UpdaterBackups/` |

共享文件来自当前用户译文的引擎通用部分，是本插件的共享语言包，**不是 Epic 官方语言包**。私有工程名称、测试词条、未完成译文与来源未核实的内容不纳入。

## 没有匹配版本怎么办？

同一个 UE 版本号也可能有不同构建。管理器按引擎文件校验值匹配，不会强行安装不匹配的动态组件。

普通用户可请发布者提供对应版本。获得源码授权的维护者可进入 **引擎编译**：

1. 选择维护者提供的本地源码 ZIP，并准备目标引擎及匹配的完整 SDK。公开安装包不包含编译源码。
   编译前会检查云端：有匹配的已验证包时直接下载，避免重复编译。
2. 安装 Visual Studio C++ 工具链，选择它的 `vcvars64.bat`；填写该引擎对应的 MSVC 版本。
3. 安装 Python 3.9 或更新版本，选择 `python.exe`。
4. 选择输出目录，检查环境，然后点击 **编译测试包**。

生成的文件带 `UNVERIFIED` 标记。**编译成功不等于已验证兼容。**先在目标引擎的独立测试工程里验证，再交给发布者加入更新清单。其他引擎版本如果改变了 C++ 接口，仍然需要适配源码，管理器不会自动修复接口差异。

编译使用独立工作目录，不会修改正在使用的插件。首次编译可能耗时数分钟。此功能面向 Windows 64 位编辑器。

## 分享编译结果，避免重复编译

在“引擎编译”页使用“检查云端构建”或“投稿已有编译包”。官方指纹且云端缺少的构建会在编译后准备投稿；定制或未认证构建先征求公开分享同意，拒绝后保留本地结果。

打开投稿页，登录自己的 GitHub 账号，将生成的 `XH-contribution-*.zip` 拖到正文后提交。云端按官方／定制分区保存，通过维护者验证后进入正式下载清单。待审核投稿不会自动安装。

投稿只包含插件编译组件、版本与引擎指纹，不含引擎文件、源码、个人词典或工程文件。查询会下载公开目录，在同意投稿之前不会发送本机的定制指纹。官方身份按维护者已登记的完整指纹判断，版本号相同不能代替认证。
