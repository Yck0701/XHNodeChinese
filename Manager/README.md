# 虚幻翻译插件 · 下载与使用说明

## 前言：为什么做这个工具

做特效时，很多 Niagara、材质和蓝图节点还是英文。查一个词、找一个节点，经常打断制作。

所以做了这个工具：把常用节点、参数和说明翻成中文，也能用中文搜索。希望新人少花时间查单词，老用户少做重复翻译，把时间留给特效本身。

## 第一次用，只看这里

**金山云下载：虚幻翻译插件-1.0.17-Windows.zip**

下载本文这一节的同名附件即可。离线说明读者请打开[金山文档下载页](https://365.kdocs.cn/l/cpi4ASG5Izsi?source=wiki)。

1. **保存工程，关闭 UE。**
2. **解压下载的 ZIP，双击「虚幻翻译插件.exe」。**不要直接在压缩包里运行。
3. **选择工程。**选你的 `.uproject` 文件，工具会自动识别 UE；只有找到多个或没有找到时，才需要手动选择。
4. **看自动检查结果，点「自动适配并安装」。**已适配就直接使用；已有包直接安装，没有包会自动下载源码、安装编译环境并完成适配。完成后打开工程，顶部会出现「虚幻翻译插件」菜单。

**已经带好常用词库，装好就能用。已有适配包无需编译；确需编译时由工具自动准备。无需 Codex 或 API 密钥。**

下载慢或没有网络：点「使用随包离线版本」，再安装。没有匹配包时，先看后面的“版本不匹配”，不要随便选一个版本。

启动时自动检查当前 UE：已安装匹配插件就提示无需编译；有安装包就提示使用或下载；确实没有匹配包才询问是否编译。手动指定引擎后会停用自动识别，点「从工程识别」可恢复。识别过程不修改工程文件或引擎关联。

## 平时怎么用

- **汉化**：打开或关闭中文显示，快捷键 **Ctrl + Alt + L**。
- **搜索**：在支持的模块、参数、蓝图和材质搜索框里，可输入英文或已有中文译名，例如 `SpriteSize`、`精灵尺寸`。也支持“大小／尺寸”等常见近义词。
- **采集**：平时关着；想补翻译时再开，采完就关。

后续下载、说明和维护记录统一看这份金山文档，软件附件存放在金山云。安装工具的自动更新版本仍在 GitHub；发现新版后会先询问是否下载。

## 有问题再看这里

**没有菜单？**在 UE 的「编辑 → 插件」中启用「虚幻翻译插件」和内置的「Python Editor Script Plugin」，按提示重启。旧版本可能显示“星河节点汉化”或“节点汉化”。旧的 UEEditorModeChinese 请先停用，避免重复处理界面。

**提示版本不匹配？**重新选择实际使用的 UE，检查更新。同是 5.8.3，官方版和定制版也可能不同，工具会检查具体构建。当前提供官方 UE 5.8.3 / CL 58210709 和已验证的定制 5.8.3 包；其他构建需要对应安装包。

**还有英文？**先确认汉化已开。没有译文的内容需要补译；少数自定义界面也可能暂不支持。中文搜索依赖已有译文，不是任意语义搜索。

**使用时卡顿？**先关闭采集、暂停模块扫描。插件 0.2.16 已减少重复词库处理，并把界面扫描分散到多帧完成；首次扫描大型模块仍可能短暂停顿，日常使用不需要一直扫描。

## 想补充翻译

### 用网页工具：最容易上手

1. 打开「采集」，展开需要翻译的界面；要采集提示说明，就把鼠标停在对应项目上。采集完关闭。
2. 在「虚幻翻译插件 → 翻译工具」选豆包或 DeepSeek。
3. 点「开始／继续翻译」，到打开的网页粘贴任务并发送。
4. 复制网页的完整回答，回到 UE 点「粘贴译文」。还有剩余时继续下一批。

JSON、带说明的代码块、表格和两列 CSV 都可识别；格式错误或缺少必要信息的条目会保留待译。中断后看「任务进度／中断后继续」，不用重新翻完。网页账号、免费额度和收费规则以所选服务为准。

### 没打开过的模块也想翻译

进入「词典与覆盖 → 扫描未打开模块」。扫描结束后再点翻译按钮，可补充模块内部参数、分组、节点注释和长说明。扫描仅在手动启动后运行，可以暂停；关闭编辑器后重新扫描会从头开始，已保存译文保留。

### 用自己的译名或人工翻译

在「词典与覆盖」中打开个人词典，每行两列，保存为 UTF-8：

```csv
"SpriteSize","精灵尺寸"
"MyCustomTerm","我的自定义词条"
```

不用表头。长说明用「编辑长文本翻译」，按整段填写中文，保留数字、占位符和属性路径。个人译文优先于共享词库。内置“本地译文复用”只复用已有翻译，不会调用在线服务。

### Codex 和 API：需要时再配置

本机有 Codex 时，在翻译工具中选择它，插件会寻找本机程序并复制请求路径；到 Codex 粘贴发送后，UE 自动导入结果。没有找到程序时，在「Codex 设置」填写安装目录或程序路径。

需要连续在线翻译时，可在「翻译工具 → API 设置」配置所选服务。API 是可选功能，按服务商规则使用；不要分享带密钥的配置文件。

## 更新、备份和手动安装

日常更新用安装工具里的「检查更新」。管理器更新会备份并替换当前目录文件，退出后自动重启；原快捷方式继续有效。当前版本与路径直接显示在安装页，可点「打开当前目录」。

从 1.0.15 或更早版首次升级时，旧程序仍按旧逻辑打开缓存目录。请在新版点一次「更新旧目录…」，选择以前使用的管理器 EXE；以后从原路径启动并原位更新。更新共享词库用「更新共享词库」，保留个人译文。想备份或恢复自己的词典，进入「词库与备份」。**“替换个人词典”会覆盖所选内容，操作前会自动备份。**

只有下载文件时，不需要关闭 UE；真正安装或替换文件前，工具会询问是否正常关闭 UE，未保存内容由 UE 提示处理。

需要手动安装时，从下方选择与引擎匹配的包，关闭 UE 后解压，把整个 `XHNodeChinese` 文件夹放进工程的 `Plugins` 文件夹。正确位置：`你的工程/Plugins/XHNodeChinese/XHNodeChinese.uplugin`。手动覆盖前自行备份个人译文。

## 会影响项目文件吗？

汉化用于编辑器显示与搜索，不会通过翻译功能重命名资产、修改参数值或保存材质、蓝图和 Niagara 逻辑。

**会写入文件**：安装或更新会写入 `Plugins/XHNodeChinese`；词典、任务、缓存和备份会写入插件自己的目录及 `Saved/XHNodeChinese`。手动配置 Codex 输出目录时，也会使用该目录。UE 自身仍可能更新缓存、配置或自动保存，因此不能说“整个工程零文件变化”。

常用文件位置（相对于工程目录）：

- 个人词典：`Plugins/XHNodeChinese/Dictionaries/User.csv`
- 个人长文本：`Saved/XHNodeChinese/LongText.csv`
- 备份：`Saved/XHNodeChinese/UpdaterBackups/`

产品虽然改名，内部文件夹仍叫 `XHNodeChinese`，升级时沿用原来的词典和设置。

## 编译和分享：维护者再看

选择工程与引擎后自动检查是否适配。点「自动适配并安装」，已有包直接使用；没有包时会进入「自动适配」页。

源码仓库已公开：<https://github.com/Yck0701/XHNodeChinese>。工具自动下载并校验编译源码，在本机缓存复用；随包也提供离线源码，无需登录 GitHub。

只需提供目标工程和 UE，点「自动适配并安装」。工具自动寻找完整的同版本 UE、Python、C++ 工具和 Windows SDK；缺少环境时从官方网站下载安装，完成后自动检测、编译和安装。也可在「自动安装 / 编译」页单独点「安装 / 修复 C++ 环境」，无需自己找 vcvars64.bat。

自动环境安装需要联网；C++ 安装可能弹出 Windows 管理员授权，部分环境安装后需要重启。定制引擎缺少 SDK 或新引擎需要源码适配时，会保留日志并显示下一步，不会把编译成功当成所有项目均已验证。

定制引擎缺少开发文件时，需要提供完整的匹配 UE SDK；管理器不能自动取得厂商未公开的开发文件。SDK 提供依赖，编译目标决定包用在哪个引擎。编译中可取消；连续 5 分钟无输出或单阶段超过 20 分钟会停止并保留日志。

生成的测试包必须在目标引擎的独立工程验证后才能发布。可以用自己的 GitHub 账号投稿；官方与定制构建分区存放，定制版分享前会征求同意，审核后才供其他人使用。

依赖安装渠道：[微软 C++ 工具](https://learn.microsoft.com/en-us/visualstudio/install/command-line-parameter-examples?view=vs-2022)、[Python 官方安装包](https://www.python.org/downloads/release/python-31316/)。

## 开发与迭代历程

- **1.0.0｜安装与备份更省心**：选择工程和引擎即可安装，个人词典可一键备份、恢复，新人少折腾环境，已有翻译也方便保留。
- **1.0.2–1.0.5｜装好就能用，更新有提醒**：内置 3 万余条常用翻译，无需翻译账号即可使用；启动检查新版，下载和安装前有提示，减少手动查版本的麻烦。
- **1.0.6–1.0.8｜节点更易懂，查找更方便**：补齐参数、节点和悬浮说明，完善中文搜索，操作界面更清晰；累计提供 32728 条词条、4217 段说明，减少查词和重复翻译。
- **1.0.9–1.0.10｜已有版本直接复用**：编译前检查本地和云端安装包，匹配时直接使用或下载，省去重复编译；确需编译时可查看进度、随时取消。
- **1.0.11｜下载和上手更简单**：统一命名为“虚幻翻译插件”，软件和说明集中到金山文档，新人按四步即可安装，后续通过管理器获取更新。
- **1.0.13｜使用更流畅，更新更稳妥**：减少重复词库处理和扫描造成的停顿，优化积压译文导入，增加跨项目路径保护与多轮验证，让日常查找、翻译和更新更省心。
- **1.0.14–1.0.15｜选工程就能识别，已有插件直接用**：自动找到工程使用的 UE，启动检查是否需要适配；已安装就直接使用，有包就复用或下载，省去重复选路径和编译，修复安装时误提示“先选择引擎”的问题。

- **1.0.17｜只选工程和引擎，自动完成适配**：源码自动获取，缺少 C++ 环境自动安装，编译后继续安装；管理器更新保留原路径，原快捷方式继续可用。
