# 虚幻翻译插件 · 管理器 1.0.17 / 插件 0.2.16

- 选择目标工程和 UE，点击「自动适配并安装」：优先复用已有包；没有匹配包时自动获取源码、准备环境、编译并安装。
- 缺少 VC 时自动下载微软 C++ 编译工具和 Windows SDK；提供显眼的「安装 / 修复 C++ 环境」入口，无需查找脚本路径。
- 编译源码现已公开，自动校验并缓存；便携包带离线源码，省去手动找授权包。
- 管理器更新在原目录备份、替换并重启，原快捷方式继续有效；界面显示当前版本和完整位置。
- 旧版首次升级后可用「更新旧目录…」回填原位置，以后原位更新。

Windows 管理员授权或系统重启仍需本人处理。目标 UE 必须包含匹配的开发文件；定制 SDK 或新版本 API 不兼容时会停止并保留日志，不跳过必要校验。

插件及共享词库沿用已验证版本：32728 条词条、4217 段说明，官方及定制 UE 5.8.3 的适配以实际引擎指纹为准。
