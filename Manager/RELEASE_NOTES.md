# 星河插件管理器 1.0.8 · Niagara 输出参数漏译修复

## 安装与升级

完整解压 XHPluginManager-1.0.8-win64.zip，打开 XHPluginManager.exe。选择工程与引擎，点击“检查更新”，再点击“安装 / 更新插件”。旧管理器也可“下载并打开新版工具”。

本次需要更新插件至 0.2.14；只更新共享词库无法修复名称匹配和输出参数漏采。安装前保存工作，UE 正在运行时管理器会询问是否正常关闭。

## 这次修复

- 连写名称与带空格名称共用完整词条译文。例如 CombinedCollisionNormal 现在显示为“合并碰撞法线”。
- 支持明确配置的编号模板。ModuleCollision 1 Normal、ModuleCollision 2 Normal 共用“模块碰撞 {Index} 法线”，保留原编号，无需分别翻译。
- 补采 Output、Transient、Particles 等命名空间下的参数显示名称。对照六个真实碰撞与涡旋模块，补回此前遗漏的 74 个不重复名称。
- 共享词库新增 39 条译文及编号模板，覆盖“本帧发生物理碰撞”“碰撞有效”“碰撞前速度”等，并同时用于中文搜索和待译去重。
- 名称匹配只使用整条词典，歧义别名不自动套用，明确个人词条优先。路径、代码表达式和长说明不会被拆词拼接。

## 验证与文件影响

标准与定制 UE 5.8.3 安装包分别在独立工程中验证，包含显示还原、中文搜索、编号保留、歧义处理、真实模块采集和原有悬浮提示回归。共享词库包含 32,728 条短词和 4,217 段长说明；这并不代表所有引擎文本都已翻译。

别名索引在加载词典时建立，显示结果沿用缓存；没有增加每帧全词库扫描或自动加载全部模块。未打开模块的深度采集仍由用户手动启动，并可暂停。

更新修改插件及备份／缓存目录，保留个人词典和长文本。显示翻译不重命名底层参数、不保存资产，不修改 .uproject 或 Config。共享译文由星河维护，并非 Epic 官方语言包。

源码保留在私有仓库，公开仓库只发布安装包及运行必需文件。
