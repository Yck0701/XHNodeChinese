# 星河插件管理器 1.0.10

编译前先检查已有版本；修复旧构建流程在 UBA 排队时长时间无产出的问题。

## 用户先这样做

解压后运行 XHPluginManager.exe。进入“引擎编译”，选择“编译目标”，点击“检测已有版本”。本地有匹配包时选择使用，云端有匹配包时选择下载。官方 UE 5.8.3 / CL 58210709 已提供验证包，无需重复编译；同版本不同指纹仍须分别匹配。

## 本次更新

- 编译目标与安装引擎分开；“以 SDK 为编译目标”可快速选择官方 SDK 对应引擎。
- 编译前检查随包离线版本、下载缓存、输出目录测试包、当前工程已安装版本及云端清单，核对完整引擎指纹、插件版本和组件哈希。
- 找到已有包时询问使用或下载；拒绝后也不会偷偷开始编译。待审核投稿会单独提醒。
- 跳过无用的示例模块编译，直接生成配置并编译实际组件，避免旧流程卡在 UBA 调度；支持中文输出路径。
- 新增取消编译、进度心跳和日志。连续 5 分钟无输出或单阶段超 20 分钟会停止本次构建并保留日志，不会结束工作中的 UE。
- 真正编译需要授权源码包 0.2.14-source-r2 或更新版本；旧构建工具会被提前拦截。源码只在私有源码仓库和授权交付中提供。

## 验证与范围

管理器回归测试通过；本机官方 UE 5.8.3 全新中文工作目录完整构建约 45 秒，含两个组件、词库和测试 ZIP。其他电脑耗时可能不同，编译成功仍需在目标引擎中验证。

插件保持 0.2.14，共享词库保持 2026.10.12.3（32728 条词条、4217 段长文本）。本次公开插件与词库 ZIP 保持上一版本相同字节。

公开仓库只提供管理器、插件运行包、共享词库和更新清单，不包含插件 C++ 编译源码或管理器源码。
