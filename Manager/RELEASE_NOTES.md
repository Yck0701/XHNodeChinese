# 星河插件管理器 1.0.5 · 更新下载与关闭 UE 提醒

## 怎么安装

完整解压 XHPluginManager-1.0.5-win64.zip，双击 XHPluginManager.exe。选择工程和引擎，再点击“检查可用更新”。

已安装旧版管理器的用户，可检查更新并点击“下载并打开新版工具”。升级到本版后，检测到更新会自动弹窗询问是否下载。

## 本版新增

- 启动自动检查或手动检查发现新版本时，列出管理器、当前工程匹配的插件、共享词库更新，询问是否下载。同一会话中的相同自动提醒只显示一次。
- 下载只缓存并校验文件，UE 可继续运行。管理器下载后询问是否打开；插件和词库下载后，点击对应安装或更新按钮应用。
- 安装插件、更新词库、替换个人词典或恢复备份时，若 UE 正在运行，列出检测到的虚幻进程，并询问是否正常关闭后继续。关闭选项默认“否”。
- 同意关闭后，保留 UE 自己的保存提示；全部虚幻进程退出后才更新文件。拒绝关闭、取消退出或 90 秒内未退出都会暂停更新，已下载的包保留，不强制结束进程。无窗口的命令行进程需手动退出。
- 备份和单独下载无需关闭 UE。离线清单可用；网络失败时读取的旧缓存不会触发新版本提醒。

## 插件与词库

沿用已验证的插件 0.2.11，提供标准与定制 UE 5.8.3 包；共享词库含 32,578 条词条和 4,205 段长说明。继续保留上一版的碰撞标签补译和翻译结果轮询优化。

更新插件或共享基础词库会备份对应旧文件，保留个人译文。主动选择“替换个人词典”或“恢复备份”才会替换相应个人文件。管理器安装与更新不写入 .uasset、.umap、.uproject 或项目 Config；UE 正常退出时的保存行为由用户在 UE 提示中决定。

源码保存在私有仓库，公开附件提供安装包。插件运行所需 Python 文件随包分发；共享译文由星河维护，并非 Epic 官方语言包。
