# 星河插件管理器 1.0.4 · 修复碰撞标签漏译与后台卡顿

## 怎么安装

解压 XHPluginManager-1.0.4-win64.zip，双击 XHPluginManager.exe。选择工程和引擎，检查更新，然后安装匹配的插件。安装前保存并关闭 UE。

已有管理器可检查更新，点击“下载并打开新版工具”；插件版本应显示 0.2.11。

## 本版修复

- 补回安装包遗漏的 115 条界面译文，涵盖碰撞模式、粒子半径、反弹摩擦、射线检测、静止状态等；当前碰撞面板抽查的 13 个漏译标签全部命中。
- 优化翻译结果检查：等待大量旧批次时，不再每 0.25 秒逐个重新查询文件。当前大型 Niagara 界面中，20 秒采样的平均检查耗时从 38.15 毫秒降至 1.30 毫秒。
- 保留批次校验、续传、乱序导入和已导入结果被修改时的检测。
- 发布前逐份核对所有基础词典，防止复用引擎二进制时带回旧词典。个人词典模板保持为空。
- 继续内置 32,578 条共享词条与 4,205 段长说明。

## 使用与性能

日常制作可保持“采集：关”；需要新增待译文本时再开启。汉化显示与搜索索引仍然有效。

以上是本机、本次界面、关闭采集时的测量，并非所有工程的帧率保证。界面汉化扫描仍有开销；大型索引、词典重载和批次导入时也可能短暂停顿。

## 文件影响

更新修改 Plugins/XHNodeChinese，并在 Saved/XHNodeChinese 下保留备份和运行缓存。个人 User.csv 和 LongText.csv 保持原样；不写入 .uasset、.umap、.uproject 或项目 Config。

源码仍放私有仓库，公开附件不包含维护用 C++ 源码和编译工具；插件运行所需 Python 文件随包分发。共享译文由星河维护，并非 Epic 官方语言包。
