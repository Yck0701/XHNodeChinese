# 星河插件管理器 1.0.1

解压 `XHPluginManager-1.0.1-win64.zip`，双击其中的 `XHPluginManager.exe`。

本版将源码仓库与公开发布仓库分开。默认更新源改为 `Yck0701/XHNodeChinese-new`；旧版保存的源码仓库下载地址会自动迁移。公开包不含 C++ 源码和维护工具，编译页改为选择授权的本地源码包。

- 按实际引擎构建匹配、下载与安装插件；插件更新保留个人词典。
- 一键备份个人词典和长文本；共享译文替换前自动备份，支持从备份恢复。
- 提供编译环境检查、目标引擎编译与独立测试包生成。
- 支持 GitHub Releases 在线更新，也可使用随包离线清单。

本次插件版本为 0.2.8，提供标准 UE 5.8.3（CL 58210709）与原定制 UE 5.8.3 两个构建。其他引擎版本需单独编译并验证，不能只改版本号安装。

共享译文版本 2026.10.10：1461 条词典、153 段长文本。已排除识别出的私有内容、空译文和来源未核实的条目。这是本插件维护的共享译文，并非 Epic 官方语言包。

验证：16 项管理器测试通过；标准引擎包实际编译成功，并通过隔离编辑器中的六项原生自检、菜单、网页/模拟 API 导入及热加载验证。

发布时上传 `manifest.json` 及所有被它引用的 ZIP，并将 Release 设为 Latest。安装、替换或恢复前请保存并关闭 UE。
