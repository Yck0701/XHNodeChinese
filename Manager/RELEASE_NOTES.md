# 星河插件管理器 1.0.9 · 编译结果云端复用

完整解压便携包，打开 XHPluginManager.exe。现有用户可在旧版中点击“下载并打开新版工具”。本次插件仍为 0.2.14，词库仍为 2026.10.12.3。

## 使用方法

“引擎编译”页新增“检查云端构建”和“投稿已有编译包”。编译前按引擎完整指纹、Win64 平台和插件版本查询云端。已有验证包时直接下载，已有待审核投稿时避免重复提交。

云端缺少构建时，已登记官方指纹的编译结果自动准备投稿 ZIP；定制或未认证构建先询问是否同意公开分享。登录自己的 GitHub 账号，将生成的 ZIP 拖入投稿正文后提交，云端会自动校验、去重并分别收录到官方／定制预发布存档。

投稿只包含插件编译组件、必要版本与指纹信息；不包含源码、引擎文件、个人词典、工程资产和本机路径。未认证的官方新版本也先征求同意，不根据版本号猜测官方身份。

投稿不等于已验证安装包：通过维护者验证后才进入正式更新清单。云端检查失败时仍可选择本地编译，不会误报“未收录”或自动投稿。客户端无需配置仓库写入密钥。
