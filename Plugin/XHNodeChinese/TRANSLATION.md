# 翻译工具设置

[返回使用说明与安装步骤](README.md)

先在 **节点汉化 → 翻译方式** 选择工具，再点工具栏的翻译按钮。工具栏会显示当前选择和处理进度。

| 你的情况 | 建议选择 |
| --- | --- |
| 想先用起来，不配置密钥 | 豆包网页或 DeepSeek 网页 |
| 已有其他常用聊天网站 | 其他网页工具 |
| 希望点击后后台连续翻译 | 自配 API，需要服务商密钥，可能收费 |
| 已安装并配置 Codex | Codex |

## 一、网页翻译：推荐新用户先用

1. 在 UE 打开采集，显示需要翻译的菜单、标签或悬停说明，完成后关闭采集。
2. 选择 **豆包网页**或 **DeepSeek 网页**，点击工具栏翻译按钮。插件会复制当前批次的任务并打开网站。
3. 在网页粘贴并发送。第一次使用可能需要登录。
4. 等待回答完成，复制 **完整 JSON 结果**，带代码块也可以。
5. 回到 UE，选择 **翻译方式 → 粘贴并导入网页译文**。
6. 导入成功后，再点击翻译按钮处理下一批，直到完成。

**其他网页工具**只复制任务，需要你自己打开常用网站。剪贴板不可用时，插件会打开任务文本，供手动复制。

如果导入失败，先检查是否复制了完整回答、是否对应当前批次。缺项、重复、错批次或遗漏占位符和路径的回答会被拒绝；可让网页工具修正后再次导入。

网页服务的免费额度、模型和收费规则由服务商决定。插件不会代替你在网页发送内容。

## 二、API 翻译：配置一次，之后后台处理

API 密钥需要在对应服务商平台申请，与网页聊天账号的免费使用额度不一定相同。

### 第一步：打开配置

选择 **节点汉化 → 翻译方式 → 配置翻译 API**，选择 DeepSeek、豆包／火山方舟或通用兼容接口模板。

插件会打开工程中的 `Saved/XHNodeChinese/TranslationAPI.json`。模板只在首次创建时写入，已有配置不会被覆盖。

### 第二步：填写并保存

通常只需填写这三项：

| 配置项 | 填什么 |
| --- | --- |
| `endpoint` | 服务商提供的完整接口地址 |
| `model` | 你已开通的模型名称或推理接入点 ID |
| `api_key` | 你自己的 API 密钥，不要发到聊天或分享给别人 |

DeepSeek 模板示例（模型名称以服务商当前提供的为准）：

```json
{
  "endpoint": "https://api.deepseek.com/chat/completions",
  "model": "deepseek-flash",
  "api_key": "在这里填写自己的密钥",
  "api_key_env": "",
  "timeout_seconds": 90,
  "extra_body": {"thinking": {"type": "disabled"}}
}
```

豆包／火山方舟的接口地址为 `https://ark.cn-beijing.volces.com/api/v3/chat/completions`，`model` 填写你已开通的模型或推理接入点 ID。

### 第三步：开始翻译

保存配置，选择 **自配 API**，然后点击工具栏翻译按钮。插件会在后台逐批翻译并导入，工具栏显示进度。

发生错误时会停止后续请求，已完成的批次会保留。修正配置或网络问题后手动继续；重启编辑器后也需要手动继续未完成任务。

## 三、Codex：已有用户可选

没有 Codex 可以跳过本节。

1. 选择 **节点汉化 → 配置 Codex 翻译连接**。
2. 按本机实际情况填写连接配置：

| 配置项 | 含义 |
| --- | --- |
| `thread_id` | 用于接收任务的现有 Codex 聊天 ID |
| `cli_path` | 本机 Codex 命令行程序的绝对路径 |
| `workspace` | Codex 工作目录的绝对路径 |
| `exchange_dir` | 用于交换翻译请求与结果的文件夹绝对路径 |

3. 保持 Codex 可用，在 **翻译方式** 中选择 **Codex**，点击翻译按钮。

插件会把请求提交到已配置的聊天，并分批读取返回结果。不要把自己的连接配置随安装包发给别人。

## 四、查看任务和停止翻译

在 **翻译方式** 菜单中，选择 **打开本次翻译任务文件夹** 可查看任务文件，选择 **停止当前翻译接收** 可停止处理。继续处理时，再点击翻译按钮或 **翻译当前采集词条和长文本**。

取消后已导入的译文会保留。网页方式需要再次点击翻译按钮才能处理下一批；API 方式在当前任务中自动连续处理。

## 高级配置与限制

- `api_key_env` 可指定存放密钥的环境变量名。使用这种方式时，将 `api_key` 留空，并确保启动 UE 的环境能读取该变量。
- `timeout_seconds` 的有效范围为 10～180 秒。
- `extra_body` 用于服务商附加参数。如果接口不支持示例中的 `thinking`，可改为 `{}`。
- 接口需要兼容 Chat Completions，返回正文位于 `choices[0].message.content`。地址应为完整 HTTPS 接口；本机 localhost 调试允许 HTTP。
- 如果直接填写 `api_key`，密钥会以明文保存在本机配置文件中。分享插件时不要附带该文件。
- 通常每批最多 24 个短词条或 4 段说明，原文约 4500 字符以内；单篇超长说明单独成批，保持完整。
- 任务保存在工程的 `Saved/XHNodeChinese/TranslationRequests`。更多文件位置见[高级说明](ADVANCED.md)。

服务入口与官方说明（2026-10-09 核对）：[豆包网页](https://www.doubao.com/chat/)、[DeepSeek 网页](https://chat.deepseek.com/)、[DeepSeek API](https://api-docs.deepseek.com/)、[火山方舟文本生成](https://docs.volcengine.com/docs/ark/text-generation?lang=en)。
