# 星河节点汉化 · 使用说明

版本 0.2.8。用于 Niagara、材质和蓝图的界面汉化与中英文搜索。**没有 Codex 也能使用。**

## 1. 先安装插件

1. 保存工程，关闭 UE 编辑器。
2. 解压安装包，找到里面的 **XHNodeChinese** 文件夹。
3. 打开你的工程文件夹，也就是放着 **`.uproject` 文件**的地方。如果没有 `Plugins` 文件夹，新建一个。
4. 把整个 **XHNodeChinese** 文件夹放入 `Plugins`。
5. 打开工程。编辑器顶部出现 **节点汉化** 菜单，就可以开始使用了。

放好后的目录应当是：

```text
你的工程/
├─ 你的工程.uproject
└─ Plugins/
   └─ XHNodeChinese/
      ├─ XHNodeChinese.uplugin
      ├─ Content/
      ├─ Dictionaries/
      └─ …
```

**检查安装位置：**应能找到 `Plugins/XHNodeChinese/XHNodeChinese.uplugin`，不要多套一层同名文件夹。

**引擎版本：**这个安装包适配当前定制的 **UE 5.8.3**。其他引擎版本或不同构建需要对应的安装包；出现版本不匹配提示时，请先查看[引擎兼容说明](ADVANCED.md#引擎兼容与重新编译)。

**没有菜单时：**进入 **编辑 → 插件**，搜索并启用 `XHNodeChinese`（星河节点汉化）和内置的 **Python Editor Script Plugin**，然后重启编辑器。不需要另外安装系统 Python。如果还装着旧的 `UEEditorModeChinese`，先停用旧插件，避免同时处理界面。

## 2. 先认识常用按钮

Niagara、材质、蓝图等编辑器顶部也有 **节点汉化** 菜单。窗口太窄时，部分工具栏按钮可能收在右侧的展开按钮里。

| 按钮 | 怎么用 |
| --- | --- |
| **汉化** | 开启或停用本插件汉化。快捷键 **Ctrl + Alt + L**。 |
| **采集** | 收集还没翻译的文本。新用户默认关闭；需要补译时再打开，采集完就关闭，减少使用中卡顿。 |
| **自动翻译** | 使用本地已有词典自动补全可匹配的译文。**不会自动请求豆包、API 等在线服务。** |
| **翻译工具按钮** | 按当前选择交给豆包、DeepSeek、API 或 Codex 翻译；在 **节点汉化 → 翻译方式** 中选择工具。 |
| **导出** | 查看待翻译数量，导出并打开可编辑的词条文本。 |

关闭采集后，已有汉化和搜索仍可使用。

## 3. 看到英文，怎么补充翻译？

推荐先用 **豆包网页**或 **DeepSeek 网页**，不用配置 API 密钥。

1. **打开采集**，在 UE 中打开需要汉化的菜单、展开参数。需要翻译悬停说明时，把鼠标停到对应项目上，让说明显示出来。
2. 看完需要采集的界面后，**关闭采集**。
3. 打开 **节点汉化 → 翻译方式**，选择 **豆包网页**或 **DeepSeek 网页**。
4. 点击工具栏的翻译按钮。插件会复制一批翻译任务，并打开所选网站。
5. 在网站对话框中 **粘贴并发送**。回答完成后，复制它返回的 **完整 JSON 结果**，也就是从 `{` 开始到对应 `}` 结束的整段内容。
6. 回到 UE，选择 **节点汉化 → 翻译方式 → 粘贴并导入网页译文**。校验通过后会应用译文。
7. 还有待翻译内容时，再点翻译按钮，继续下一批。

不需要自己编写 JSON。网站可能要求登录；免费额度和收费规则以网站为准。

想让插件在后台连续翻译，可以稍后按[翻译工具设置](TRANSLATION.md)配置 API。

## 4. 中英文都能搜索

在已支持的新增模块、参数、蓝图和材质搜索界面中，可以尝试：

| 输入 | 用途 |
| --- | --- |
| `SpriteSize` 或 `精灵尺寸` | 用英文原名或中文译名查找 |
| `Particles 尺寸` | 混合英文路径与中文词语查找 |
| `精灵大小` | 利用“大小／尺寸”同义词查找 |

同义词目前包含“大小／尺寸”“颜色／色彩”等有限规则，不是任意语义搜索。中文搜索依赖已有译文，找不到时可先用英文搜索，再采集并补译。

## 5. 想自己改译名？

打开 **节点汉化 → 编辑自定义词典**，每行填写一组“英文原文”和“中文译文”：

```csv
"MyCustomTerm","我的自定义词条"
"SpriteSize","精灵尺寸"
```

**只需两列，不必写表头。**以 UTF-8 编码保存后，等待约 3 秒即可自动加载。

整段说明请使用 **编辑长文本翻译**，在对应原文右侧填写完整中文。占位符、属性路径、代码标识符和数字请保持不变。

## 6. 常见问题

| 遇到的问题 | 先这样处理 |
| --- | --- |
| 有些内容还是英文 | 检查汉化是否启用，再打开采集、显示对应内容并补译。少数自定义绘制界面可能暂不支持。 |
| 节点名或属性名没有汉化 | 在 **编辑器偏好设置 → 区域和语言** 中检查本地化属性名、节点及引脚名称的设置，然后重新打开对应编辑器。 |
| 使用中变卡 | 先关闭采集，日常使用不必一直开着。 |
| 网页结果无法导入 | 复制当前批次的完整 JSON，避免只复制部分译文或上一批的回答。 |
| 没有待翻译内容 | 先打开采集并显示目标界面；已翻译的内容不会重复提交。 |
| 提示引擎版本不匹配 | 使用与引擎构建匹配的插件包，不要强行修改版本号绕过检查。 |
| 想恢复原来的显示 | 点击 **汉化** 按钮停用，或按 **Ctrl + Alt + L**。 |

## 7. 更新、停用和分享

- **更新前先备份：**关闭 UE，备份工程里的 `Plugins/XHNodeChinese` 和 `Saved/XHNodeChinese`。安装包里的个人词典为空，覆盖更新后需要恢复自己的 `Dictionaries/User.csv`。
- **完全停用：**在 **编辑 → 插件** 中停用本插件并重启编辑器。
- **分享给别人：**发送发布安装包，不要直接打包自己的已安装目录，以免带上个人词典或配置。对方也需要匹配的引擎版本。
