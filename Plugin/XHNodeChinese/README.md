# 星河节点汉化 0.2.10

## 先安装，再翻译

1. 关闭虚幻编辑器，将适合当前引擎版本的 `XHNodeChinese` 文件夹放入工程 `Plugins` 目录。
2. 打开工程，启用 Python Editor Script Plugin 和星河节点汉化，按提示重启。
3. 在“节点汉化”菜单检查“汉化：已启用”。工具栏保留汉化、翻译、采集三个按钮。

## 用豆包或 DeepSeek

1. “节点汉化 → 翻译工具”选择豆包或 DeepSeek。
2. 点击“开始／继续翻译”，在打开的网页粘贴任务并发送。
3. 复制网页回答，回到 UE 点击“粘贴译文”。JSON、带说明的代码块、Markdown 表格、两列 CSV 均可识别。
4. 再点“开始／继续翻译”，继续剩余词条。

回答不完整也可以导入有效条目。未知编号、重复条目或其他任务的回答不会混入词典；占位符、数字、属性路径遗漏的条目保留待译。普通散文和损坏的 JSON 无法可靠匹配，请让网页工具按任务中的格式重答。

中断后不用寻找旧网页回答：打开“任务进度”，再点“开始／继续翻译”。暂停的任务也可继续。旧任务在“翻译工具 → 找回历史翻译任务”；每次复制的原回答、失败原因及已导入结果保存在任务文件夹。旧版本任务没有历史记录文件时，仍可继续当前保存的任务。

## 用本机 Codex

默认无需填四项配置。选择 Codex，点击翻译，插件会自动寻找本机程序、复制一小段请求路径并打开应用。在 Codex 对话中粘贴发送，返回的文件由 UE 自动导入。

没有找到程序时，“翻译工具 → Codex 设置”只需填写 `cli_path`（Codex 安装目录或 codex.exe）。`thread_id` 可留空。已有用户指定的聊天 ID 配置继续支持直接发送，不自动猜测其他聊天。失败后继续使用原请求，不重建任务；“复制 Codex 请求路径”可随时找回当前请求。

## 补齐没打开过的模块

点击“词典与覆盖 → 扫描未打开模块”。插件先扫描名称和摘要，再逐个读取 Niagara 模块内部的参数、折叠分组、枚举选项、提示说明和节点注释，不需要逐个打开模块界面。完成后点击翻译按钮，未匹配的短词条和长文本会自动纳入任务。

内部扫描仅在手动启动时加载资产，不保存资产；每次处理一个模块并留出间隔。大型模块首次加载仍可能短暂停顿，可以随时点击“暂停模块扫描”，再点“扫描未打开模块”继续本次进度。关闭编辑器后再次扫描会重新开始；已导出的词条和译文保留。“查看模块覆盖情况”显示进度和读取失败数量。日常使用不会自动进行内部扫描。

能复用的引擎中文存入当前工程独立缓存，不大量写入个人词典。运行时生成、未序列化的标签仍需打开对应界面并开启“采集”。扫描不等于自动生成未知译文；未知内容仍需网页工具、Codex、API 或人工完成。没有启用或挂载的插件不在扫描范围内。

## 文件与高级选项

- 个人词典：插件 `Dictionaries/User.csv`。
- 长文本：工程 `Saved/XHNodeChinese/LongText.csv`。
- 未打开模块待译：`Saved/XHNodeChinese/Indexed.csv`。
- 可重建的引擎译文缓存：`Saved/XHNodeChinese/IndexedTranslations.csv`。
- 任务：`Saved/XHNodeChinese/TranslationRequests`，或原有 Codex 配置指定的目录。
- 双语显示、历史导出、重新索引、诊断放在“高级选项”。

词典保存为 UTF-8，两列 `"英文","中文"` 即可。网页工具需要用户手动复制回答，不读取网页账号；免费额度以服务商为准。API 是独立可选方式。

更多设置：[翻译工具与 API](TRANSLATION.md)、[高级说明](ADVANCED.md)。

## 内置共享词库

本版含 32578 条通用词条、4205 段说明，安装即用。个人词典和个人长文本优先。用配套管理器的“更新共享词库”获取新版本，不必覆盖个人译文。
