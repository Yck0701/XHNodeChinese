# 0.2.3 采集开关与漏采修复

- 工具栏及“节点汉化”菜单新增“采集：开 / 关”，默认关闭。独立于汉化、自动翻译和中英文搜索。
- 关闭采集时，底层不新增待译记录，扫描间隔由原来的 50 毫秒调整为 250 毫秒；开启时为 100 毫秒。已绑定的翻译仍随原始文本更新。
- 暂停时通过文件修改时间检查继续接收手动译文和 Codex 返回结果，不再每三秒重读并处理全部导出词条。常规状态记录使用摘要，避免枚举全部控件及搜索名称。
- 新增模块菜单直接采集候选项的说明，图表菜单同时采集节点说明；不会为采集触发预览视频。独立悬浮提示窗口纳入扫描。
- 未译文本去重缓存到成功写入后才清除，修复短暂出现的提示在三秒写出周期内丢失的问题。
- 普通富文本标签扩展到其他面板；含装饰标签的富文本不直接替换，保留原有标记和行为。可编辑字段仍跳过。
- 补充材质域与着色模型等下拉选项的界面词典（包括 Surface、User Interface），个人词典优先。
- 截图中的碰撞模块长说明已有采集记录但译文为空；新增完整译文，保留 [Transient]CollisionValid、属性名称和资源路径。

验证：50 项 Python 测试通过。目标 UE 中显示、Niagara 搜索、蓝图/材质搜索与新增采集原生测试通过；测试真实独立提示窗口、短暂显示保留、去重确认、普通富文本、输入框保护及停用恢复。集成测试确认采集关闭后连续七秒不改写导出文件、已有汉化仍工作、手动译文仍能导入，且热重载保留采集关闭状态。
