# Niagara 新增模块中英文搜索（0.2.0）

- 打开新增模块菜单时，索引当前上下文的全部候选项，包含尚未展开的分类。
- 词典中的中文模块名和分类加入临时搜索关键词，英文原名和英文关键词保持有效。
- 中文支持子串搜索，例如“速度”匹配“添加速度”。个人词典优先，保存后重新构建索引。
- 分类富文本和模块行应用完整译文。包含富文本标记的内容不做碎片替换。
- 未匹配的模块名和分类进入原有实时导出流程，可用个人词典或“交给 Codex 翻译”补齐。
- 关闭汉化或卸载组件时恢复搜索字段与文字绑定。不会改写模块资产、属性路径或执行回调。

原生测试调用 Niagara 引擎自身的匹配及权重函数，验证英文、中文、中文后半部分、分类、原关键词、混合查询、个人译名更新、重复索引、执行回调身份、关闭恢复和外部修改保护。另测富文本动态属性和恢复。

组件依赖当前项目引擎及 Niagara DLL 指纹。引擎升级后须重新编译与验证。
